## Reading the Display

The 7-segment displays show 32 bits (8 hex chars) at a time; KEY0 scrolls segments, LEDG[1:0] shows which one:

| LEDG[1:0] | Shows |
|-----------|------------|
| 00 | data[31:0] |
| 01 | data[63:32] |
| 10 | data[95:64] |
| 11 | data[127:96] |

**Assembling the full value:** read segments in order 11, 10, 01, 00 and concatenate:

```
ciphertext[127:0] = seg11 & seg10 & seg01 & seg00
```

## Online Verification

- Step-by-step: https://www.cryptool.org/en/cto/aes-step-by-step
- Quick check: https://aesencryption.net

Always use **ECB mode, 128-bit key, no padding**.
